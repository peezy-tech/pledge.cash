# Glossary

| Term | Meaning |
| --- | --- |
| Boardroom | An on-chain project account with its own share token, treasury, grants, distributions, liquidity positions, and lifecycle status. |
| Boardroom owner | The address allowed to perform owner-only Boardroom actions while the Boardroom permits them. |
| Share token | The ERC20 token minted by a Boardroom. Often the project's token. |
| Grant | An escrow-backed token right that can vest and be settled over time. |
| Issuer | The address or Boardroom that creates a grant and escrows grant tokens. |
| Holder | The wallet currently allowed to settle a grant. |
| Settlement | The act of claiming or purchasing vested tokens from a grant. |
| Payment token | The token paid by a buyer or grant holder when a sale or paid grant requires payment. |
| Fixed-price sale | A distribution that sells a fixed amount of Boardroom share tokens at a configured price. |
| Migrating bonding curve | A curve-based distribution that can eventually migrate reserves into liquidity. |
| AMM | An automated market maker that lets users swap between token pairs and provide liquidity. |
| Locked liquidity | Boardroom-owned LP principal held in a locker until wind-down rules allow exit. |
| Wind-down | A Boardroom lifecycle state where active issuance closes and assets are prepared for redemptions. |
| Redemption | Burning Boardroom shares to receive registered redeemable assets after redemptions open. |
| Service layer | Optional hosted context such as project profiles, verified social accounts, dashboards, alerts, and audit logs. |
| Permissionless protocol | The deployed contracts that wallets can inspect and interact with directly. |
