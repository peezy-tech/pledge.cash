# pledge.cash

pledge.cash is an unreleased workspace for token-backed projects. A project uses one
Boardroom to hold assets and issue shares, escrow-backed grants for contributors, and a
canonical Uniswap v4 position locker for project-owned liquidity.

There is no live pledge.cash deployment yet. Ethereum Sepolia and Base Sepolia are
configured as testnet candidates, but their artifacts remain pending. You can read the
product and run every local proof without sending a public-network transaction.
